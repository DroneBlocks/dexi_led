# Examples

Teaching scripts. Not installed: run them from the source tree with the DEXI workspace sourced.

## Python

| Script | What it does |
|---|---|
| `python/set_ring_color.py` | Set the LED ring color through `/dexi/led_service/set_led_ring_color` |
| `python/test_visualization.py` | Exercise the LED visualization bridge (simulator) |

Run with `python3 examples/python/<script>` from the package directory.
